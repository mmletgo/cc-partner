# 健康提醒：仅用户活动时触发（含固定间隔模板）

## 问题根源

提醒触发的唯一入口是 `src-tauri/src/health/mod.rs` 的 `collect_fired_templates()`（由每分钟 daemon 的 `handle_sample` 调用）。判定函数 `should_fire_template`（`templates.rs:140-166`）中：

- **Sedentary（久坐）模板**：已要求 `MachineState::Working`（活动相位），空闲时不触发 ✓
- **Interval（固定间隔）模板**：只看 `now - last_completed_ts >= interval`，**不看活动状态** → 用户空闲（Idle/Resting）时照常弹提醒 ✗

状态机语义（`state.rs`）：`Working` = 最近 `breakSeconds`（默认 5 分钟）内有键鼠活动；`Idle` = 从未检测到活动；`Resting` = 连续无操作 ≥ `breakSeconds`。选 `Working` 相位作为"用户活动"判据（与 Sedentary 模板一致，避免用户阅读屏幕短暂停歇时漏提醒）。

**已确认的产品决策**：macOS 未授权输入监控/辅助功能（或 Linux 无 X display）时采样器降级为恒空闲，此时**豁免活动门控、维持现状按时间间隔提醒**，避免用户设了提醒却静默失效。

## 改动内容

### 1. `src-tauri/src/health/monitor.rs`
`DeviceQuerySampler` 新增 `pub fn is_available(&self) -> bool`（返回 `self.state.is_some()`，含中文 docstring）——暴露采样器是否处于降级模式。

### 2. `src-tauri/src/health/mod.rs`
- **`HealthRuntime`** 新增字段 `monitoring_available: AtomicBool`（默认 `false`）：true = 键鼠采样可用，活动门控生效；false = 降级模式，门控豁免。同步更新 `new()` 与结构体 docstring。
- **`start_health_daemon`** 采样线程：闭包额外捕获 `state` 的 clone，创建 `DeviceQuerySampler` 后立刻 `store(sampler.is_available())` 一次。
- **`collect_fired_templates`** 在 reconcile / `clear_sedentary_window_flags` 之后、逐模板判定之前加整拍活动门控：

```rust
// 活动门控：用户不在场（非 Working 相位）时本拍不触发任何模板（含固定间隔）；
// 采样不可用（无权限降级）时无法判定活动，豁免门控维持按时间提醒。
let unmonitored = !runtime.monitoring_available.load(Ordering::Relaxed);
let user_present = unmonitored || matches!(machine_state, MachineState::Working(_));
if !user_present { return Vec::new(); }
```

同步更新该函数 docstring。`should_fire_template` 本身**不改**（门控在 collect 层统一覆盖两类模板，将来新增触发类型自动被覆盖）；`handle_sample` 不改。

**行为结果**：空闲到点不消耗计时（pending 不置位、`last_completed_ts` 不动、不写 `habit_records(triggered)`）；用户恢复活动后下一拍（≤60s）转 Working，若间隔条件早已满足则立即触发一次补提醒。

### 3. 新增单元测试（mod.rs `tests` 模块）
`collect_fired_templates` 是私有函数，可用纯内存 `HealthRuntime` 直接单测（`machine.state` 是 pub 字段可直接赋值）：
- Idle / Resting 相位 + 采样可用 → 间隔已到的 interval 模板**不**触发（fired 为空且 pending 未置位）
- Working 相位 → 照常触发
- `monitoring_available=false`（降级）+ Idle → interval 照常触发（豁免生效），同时 Sedentary 仍不触发（豁免只作用于活动门控，不改变相位判定）

### 4. 文档同步
- `src-tauri/AGENTS.md` 健康提醒章节（L524 架构 / L526 采样降级 / L528 提醒触发 / L530 HealthRuntime 字段）：补记活动门控与降级豁免行为。
- `docs/prd.md` §2.11：功能点补一条"仅活动时提醒"规则（空闲不弹任何提醒含固定间隔；恢复活动后补触发；采样不可用时豁免）。
