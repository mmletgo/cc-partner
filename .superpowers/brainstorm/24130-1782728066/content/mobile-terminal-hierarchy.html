处理规则

Worktree 是顶部上下文选择器；切换后加载该 worktree 的 window 列表、文件树和 Git 状态。Window 是移动端可切换的一级终端标签。Pane 不拆成 React 子面板，而是保留在 xterm 中，由 tmux 负责 split layout、active pane 和 status bar。
