VISIBLE → HANDOFF → DELIVER · 09

模型在变，
我想解决的问题没变

CLI Agent 负责生成与推理，cc-partner 把工程现场、Agent 资产与开发周边收成一条可见流程。

VISIBLE可见

项目、worktree、终端、阻塞与验证状态持续可见。

HANDOFF可接手

桌面、远端设备和手机保持同一个项目上下文。

DELIVER可交付

文件、Git、浏览器 smoke 与 evidence 一起收口。
