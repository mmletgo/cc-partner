|--------|---------|
| 五段分区（用户指令 / 项目指令 / 资产 / 同步 / 诊断）为主导航 | **按 Agent → 范围 → 五 Tab** |

| 提供「停止管理并保留文件」 | **不提供** |
| 提示词以双模式切换或矩阵为主 | **三栏固定：块 \| 合成预览 \| 原始文件** |
| 打开提示词自动 parse 块 | **初始仅加载原始；块与预览为空**，用户手动解析或手填 |
| peer 用户级只读 | peer **完整读写**（仅动作集限制） |
| MCP 凭据 UI 脱敏 | **UI 不脱敏**（局域网信任模型；工程日志仍避免无必要落盘明文） |
| 项目级仅本机项目 | 无设备切换，但项目选择器含 **远端项目** 并可完整项目级管理 |
| 跨 Agent 仅选择性 | 另支持 **Claude 全量适配 + 强制预览** |

后端基座（Canonical / Revision / CAS / Snapshot / support-manifest / 固定 LAN 无鉴权）不推翻；写能力仍受 manifest 与阶段一真实写盘合同约束。

## 2. 产品阶段与交互映射

| 阶段 | 产品能力 | 交互落点 |
|------|----------|----------|
| 一 | 本机用户级/项目级提示词 + 四类资产真实管理 | Agent 工作台 · 范围 · 五 Tab · 三栏同步 / 资产列表 |
| 二 | 同 Agent 局域网 Pull / Push | 工具栏拉取/推送；用户级设备切换；项目级远端项目身份 |
| 三 | 同机跨 Agent 适配 | 独立全页；选择性 + Claude 全量；皆强制预览 |

整体姿态：**高密度工作台（方案 A）**——日常本机零向导；仅跨 Agent 进独立全页。

## 3. 信息架构（壳层）

### 3.1 导航层级

```text
Agent Hub
├─ Agent 切换：Claude | Codex | OpenCode（三端同级）
├─ 工具栏：拉取… | 推送… | 适配到其他 Agent…
├─ 范围：用户级 | 项目级
│   ├─ 用户级：设备切换器（本机 | 局域网 peer）
│   └─ 项目级：项目选择器（本机项目 | 远端项目）— 无设备切换器
└─ 五 Tab：提示词 | Skill | Command | MCP | Plugin
```

上下文三元组（用户级）或四元组（项目级）：

- 用户级：`Agent × 用户级 × Device`
- 项目级：`Agent × 项目级 × ProjectIdentity`（`ProjectIdentity` 含本机或 `deviceId + path` / workbench project 引用）

五 Tab 的数据与写目标**始终**跟随当前上下文。

### 3.2 用户级 · 设备

- 列表：本机 + 当前可达局域网设备（文案用「局域网设备 / 对端」，避免「已认证 / 可信 / 安全设备」营销语）。
- **本机与 peer 均为完整读写**（编辑、同步、启停、卸载、MCP 含明文凭据）；写走该设备 Hub/P2P 路径，preview → apply。
- 切换设备 = 切换正在查看/管理的**该 Agent 用户级**库存；不换 Agent 类型（Claude 视图只对齐对端 Claude）。
- **动作限制**（不是只读）：
  1. 「适配到其他 Agent」仅**同机**；在 peer 上下文禁用或引导回本机。
  2. 推送：源为当前设备视图中的内容；目标为用户多选的其他 peer。
  3. 离线 peer 不可作为写目标；列表标离线。

### 3.3 项目级 · 无设备切换 · 可管远端项目

- 项目选择器分组：**本机项目** | **各 peer 下的远端项目**（发现策略复用 Workbench 远端项目能力，不另造扫盘产品）。
- 选中远端项目后：同一套五 Tab / 三栏 / 资产手势；写目标为**该项目所在设备**上的项目原生路径。
- 跨 Agent 项目适配：固定**同一项目根路径语义** + 目标 Agent **Hub opt-in** 门闩；不在适配流中跨项目乱指。

### 3.4 工具栏动作与阶段二/三入口

| 动作 | 行为 |
|------|------|
| 拉取… | 阶段二 Pull 向导（见 §5） |
| 推送… | 阶段二 Push 向导（见 §5） |
| 适配到其他 Agent… | 进入阶段三**独立页**；默认源 = 当前 Agent；带上当前范围（用户级或当前项目） |

## 4. 提示词 Tab（三栏）

### 4.1 布局

桌面默认**三栏并排**，同时可见：

| 栏 | 名称 | 可编辑 | 职责 |
|----|------|--------|------|
| ① | 块 | 是 | 公共块 / 当前 Agent 专属块 / needsAdaptation 标记；增删改排序 |
| ② | 合成预览 | **否** | 由块合成的逻辑视图；相对 ③ 的 diff 摘要 |
| ③ | 原始文件 | 是 | 当前生效（或 inventory 选中）原生路径全文 |

窄窗：保持三栏信息架构（横向滚动或分段切换），**不得**退化为「唯一真源是双模式切换」。

顶区：生效路径、管理/漂移状态、重新扫描、**同步到原生文件…**。

### 4.2 初始状态（硬规则）

1. 打开提示词时：**读取并展示用户已有原始文件**到 ③（无文件则空态，可 preview 创建默认路径）。
2. **① 块与 ② 预览初始为空**。
3. **禁止**打开时自动 parse 成块。
4. 用户路径二选一（或组合）：
   - 在 **③ 原始文件栏** 点击 **「从原始重新解析块」** → 填充 ① 并生成 ②（可撤销到解析前）；
   - 在 ① **手动填写**块 → ② 跟随重算。

「从原始重新解析块」控件**仅放在原始文件栏**，不放在块栏或全局模糊入口。

### 4.3 双源编辑与合流

- 只改 ①：② 即时跟随（草稿）；③ 在同步前保持加载的磁盘/上次基线；状态「块侧脏」。
- 只改 ③：原文脏；可再点「从原始重新解析块」覆盖 ①②；未解析前 ② 可提示与块模型不一致。
- ① 与 ③ **同时脏且内容分歧**：同步前强制选择基线——以块合成写入 / 以原始写入（并可选重解析）/ 取消。
- 同步成功后：rescan，①②③ 与写入结果对齐。**写死规则**：
  - 以块为基线写入 → 保留当前块模型，② 与 ③ 反映新磁盘内容；
  - 以原始为基线写入 → 按写入结果 **自动 re-parse 一次块** 填入 ①②，避免三栏立刻分叉。
  - 上述「同步后 re-parse」**不等于**打开 Tab 时自动 parse；打开时 ①② 仍必须为空直到用户手动解析/手填，或直到本 Tab 内完成过一次成功同步后的对齐。

### 4.4 同步

- 提示词写盘默认唯一主入口：**同步到原生文件…**
- 流程：路径级 preview（创建/修改/遮蔽/冲突）→ 用户确认 → apply → rescan。
- 上下文在 peer 或远端项目时：手势相同，目标为该上下文原生路径。
- **只写当前 Agent**；不因同步偷偷写其他 Agent。
- manifest 写 blocked：可编辑草稿，同步禁用并展示原因。
- 脏草稿切换 Agent/范围/设备/项目/Tab：确认丢弃或保留会话草稿。
- 外部修改：必须先处理（重载 / 确认覆盖 / 取消）再同步。
- 多文件（如 Codex override 遮蔽 base）：展示 active + 相关文件；默认同步 active；管理 override 需显式选择（延续 instruction V2 安全边界）。

### 4.5 与阶段三的关系

块模型与跨 Agent 页共用。本 Tab 同步从不跨 Agent。源侧块为空时，跨 Agent 页引导回本 Tab 解析/手填，或在适配页提供「从源原始解析块」后再分类。

## 5. 四类资产 Tab

### 5.1 布局

Skill · Command · MCP · Plugin **等权**子 Tab；布局同构：

- 搜索 + 筛选（启用状态、一致性/漂移/冲突/不支持）
- 主列表 + 详情（右侧或 Drawer）
- **无**三 Agent 列矩阵（Agent 已在顶栏选定）

### 5.2 发现即管理

- 扫描进入列表的同时建立或对齐 Hub 管理记录。
- **无**「纳入 Hub / Adopt」主操作；启停、卸载、编辑、推送直接可用（写能力允许时）。
- 首次发现：随 refresh 完成纳管；不插阻断向导；失败项标错并可重试刷新。
- 大批量首次扫描：刷新可显示进度/可取消。

### 5.3 用户可见状态

| 状态 | 含义 |
|------|------|
| 一致 | 磁盘与 Hub 意图一致 |
| 漂移 | 外部或它端变更，需处理 |
| 冲突 | 无法安全自动合并 |
| 不支持 | manifest/adapter 无法管理 |

**不提供**「停止管理并保留文件」。卸载/删除仅通过 preview 写清原生侧后果（建议实现默认：按 kind 合同移除启用/文件；Hub revision 可留作恢复——细节在 implementation plan，交互上用户看到的是卸载预览而非「停止管理」）。

### 5.4 专属字段与动作

- **Skill**：invocation、目录摘要；启用/停用/卸载  
- **Command**：触发名、参数提示；同上  
- **MCP**：transport、command/url、**凭据明文展示与编辑**；启用/停用/卸载  
- **Plugin**：组件矩阵；删除预览闭环  

写路径：危险变更 preview → apply → rescan。发现即管理**不等于**静默改盘。

### 5.5 非目标

- marketplace  
- 在资产 Tab 内一键跨 Agent 转换（走 §6 独立页）

## 6. 局域网（阶段二）

### 6.1 两种姿势

| 姿势 | 用途 |
|------|------|
| 用户级切换设备 / 项目级选远端项目 | **就地**远程管理（完整读写） |
| 工具栏拉取 / 推送 | 设备间**复制或覆盖**快照，不必先切入浏览 |

### 6.2 拉取

- 入口：工具栏「拉取…」。
- 默认源：若当前设备已是 peer 则该 peer，否则用户选源。
- 内容：当前 Agent 下用户级或项目级提示词与/或四类资产（多选）。
- 目标：默认本机对应范围；项目级带 project 身份，未映射不猜路径。
- 冲突策略：`skipExisting | replaceAfterPreview`。
- **仅同类 Agent**（Claude→Claude 等）。

### 6.3 推送

- 入口：工具栏「推送…」。
- 源：当前上下文中的选中项或明确全选范围。
- 目标：1..N 其他在线 peer（同类 Agent）。
- 每目标 preview 后确认；逐设备成功/失败报告与重试。

### 6.4 边界

- 禁止跨 Agent 远端互传。
- 不做后台全量镜像。
- MCP 凭据 UI 不脱敏；传输仍走既有 Snapshot/P2P 合同。

## 7. 跨 Agent 适配（阶段三 · 独立页）

### 7.1 入口与范围

- **独立全页**，非工具栏轻量 Drawer 应付。
- 从各 Agent 工具栏「适配到其他 Agent…」进入；源 = 当前 Agent；带上用户级或当前项目。
- **用户级与项目级均支持**。
- 项目：同路径 + 目标 opt-in；未 opt-in 时页内先走启用预览。
- **仅同机**；peer 设备上下文禁用本能力或强制源=本机。

### 7.2 模式 A · 选择性适配

1. 选目标 Agent（1..N，不含源）  
2. 确认范围  
3. 勾选提示词块与/或资产  
4. 规则分类：**共同 / 差异 / residual**  
5. 差异：手改，或「用 Claude 适配此块」→ Accept / Edit / Reject  
6. 预览各目标路径与 diff → 确认一次性 projection  

- 禁止无脑整文件提示词同步。  
- residual 默认不写。  
- 源块为空：引导解析或本页「从源原始解析块」。

### 7.3 模式 B · Claude 全量适配（新增）

- 将源 Agent × 当前范围（用户级整包或当前项目整包）的**全部配置**（提示词 + 四类资产）一次适配到**目标 Agent**。
- 建议一次一个目标 Agent；若 UI 允许多目标，则**按目标串行**各生成一方案。
- 全量内容清单在预览中**按 kind 逐项列出，不得漏类**。
- 本机 Claude Code headless/pure 生成结构化适配方案（每项：create/update/skip、路径、内容或 residual 原因）。
- **强制全量预览**：无「跳过预览直接写」；用户可逐项取消/skip、整单驳回或确认写入。
- Claude 不可用：全量按钮禁用并说明；选择性 + 规则仍可用。
- 启动前简短说明将调用本机 Claude、可能耗时。

### 7.4 适配引擎（混合）

- 规则适配先跑并标注。  
- 难块 / 全量语义：Claude 进程；**仅方案**，Accept/确认前不写盘。  
- **无** sidecar 后台跨 Agent 持续收敛；外部编辑只更新 inventory，再适配需重新进页确认。

### 7.5 资产适配诚实性

- Skill：尽量 portable；invocation 差异 adapted。  
- Command：无统一模型时不伪装原生 slash。  
- MCP：字段子集映射；凭据原字节；未知字段保留。  
- Plugin：分解 capability；hook/runtime residual 不自动转码；partial 点名 blocker。

### 7.6 写盘

确认后对各目标独立 apply；部分失败可重试；成功项遵循发现即管理。

## 8. 空态、错误、深链与迁移

### 8.1 空态

- Agent 未安装或写 blocked：结构可见，动作禁用 + 原因。  
- 无原生指令文件：③ 空 + 可创建；①② 空。  
- 无资产：区分无库存 vs 扫描失败 vs 对端离线。  
- 无 peer：设备仅本机；拉/推说明无对端。  
- 全量适配 Claude 不可用：禁用 + 引导。

### 8.2 错误

- 所有写：preview → apply → 逐项结果；禁止整页假成功。  
- 漂移与双源分歧：写前强制策略选择。  
- 推送部分失败：可重试失败目标。  
- 可导航进 Attention 深链回 Hub（复用既有 attention 合同）。

### 8.3 深链

新查询参数应能恢复：`agent`、`scope`（user|project）、`tab`、`deviceId`（用户级）、`project` 身份（项目级）、以及适配页模式等。旧 `section=userInstructions|assets|…` 映射到新 IA，避免书签全断。

### 8.4 迁移

- 主路径替换五段分区 + target 矩阵 UI。  
- 不恢复 `/claude-code` 独立页；旧路由继续指向 Agent Hub 等价上下文。  
- 诊断类（probe/support）可收入设置或 Agent 页次要「环境」入口（implementation 定），不阻挡主 IA。

## 9. 成功标准（交互）

1. 用户在单一 Agent 上下文内完成用户级与项目级（含远端项目）提示词三栏与四类资产管理。  
2. 提示词：初始见原始、块/预览空；能从原始栏解析块；能同步且必 preview。  
3. 资产：发现即可管理，无 Adopt、无「停止管理保留文件」。  
4. 用户级能切换设备并对 peer 完整读写；能同类 Pull/Push。  
5. 能进入独立页做**选择性**或 **Claude 全量**跨 Agent 适配，且皆强制预览。  
6. 无后台跨 Agent 自动写盘；无未 preview 落盘。

## 10. 明确非目标

- 新增 LAN 鉴权或 capability token  
- 后台跨 target 自动同步  
- 全量 home 目录镜像  
- LLM 静默改全库不经预览  
- 宣称未执行的多机/全平台 L3 已通过  
- marketplace
